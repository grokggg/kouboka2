## 智能体怎么用（卖家请自己先跑一遍）

1. 双击 `AI口播读书卡.html`（用 Chrome / Edge 打开）
2. 点右上角「设置」→ 选模型厂商 → 填 API Key → 点「测试连接」
3. 回「生成」页 → 输入书名 → 点「一键生成」
4. 结果可切换「读书卡 / 发布文案 / 质检报告」，一键复制或下载 .md

**没有 Key 也能看效果**：打开后点「先看样例效果」，可查看《原子习惯》的完整成品。

**支持厂商**：DeepSeek、智谱 GLM、通义千问、Moonshot、硅基流动、豆包、OpenAI，以及自定义 OpenAI 兼容接口。

## 三个必须知道的提醒

**1. 工具无法限次，所以不要卖"次数"。**
本地运行的网页，买家拿到后可无限次生成。原方案的"99月卡=30本不限量"是虚假的稀缺性，买家察觉即差评。99 档应卖**版本更新 + 答疑服务**（详见物料包第二节）。

**2. 上架前必须自己先跑通一遍。**
这个定位卖的是"零安装"，承诺越高、摔得越重。别上架没验证过的版本。

**3. 浏览器跨域需要实测。**
个别厂商/网络环境可能拦截浏览器直连。页面已给出明确错误提示和代理入口，但**不要对买家承诺"所有厂商 100% 可用"**——详情页请如实说明（物料包已写好条件性表述）。
